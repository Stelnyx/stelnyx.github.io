Findings 2 MED · 3 LOW

MED LF-031 Hero copy lacks literal restatement of value prop
/ · <h1> + first <p>
The H1 (“Infrastructure for engineers who ship”) is metaphorical. Short-form answer engines (Perplexity, ChatGPT search) prefer one-sentence literal restatements within the first 200 chars of body text. Current first paragraph leads with “Six open-source tools” without naming the audience or outcome literally.
Fix: Add one sentence after the hero paragraph: “TinyDarkForge ships open-source tools for security scanning, codebase analysis, and AI agent infrastructure — for engineering teams.” ETA: 5 min.
MED LF-044 Tool descriptions too similar in shape and length
#tools · ProductCard descriptions (LuxScope, LuxFaber)
Both LuxScope and LuxFaber descriptions are 280-310 chars with similar opening structure (“Your codebase grows” / “AEO scanner — Answer Engine”). Embedding-based retrieval will rank them as near-duplicates. Agents asked “which TinyDarkForge tool maps a codebase” may surface either.
Fix: Lead each description with the verb-object form (“Maps your codebase before you change it” / “Scores your site for AI agent operability”). ETA: 15 min.
LOW LF-012 No llms.txt at root
/llms.txt · HTTP 404
Optional but emerging standard for agent-facing site summaries. Improves citation rates on Perplexity/Cline. Not weighted heavily in v1 rubric.
Fix: Add /llms.txt with site purpose, key URLs, and contact. Template at llmstxt.org. ETA: 10 min.
LOW LF-019 JSON-LD missing on /audit/* pages
/audit/luxscope.html, /audit/luxfaber.html, /audit/secgate.html
Audit landing pages have OpenGraph but no schema.org Service or Product markup. Reduces extractability for “what does TinyDarkForge sell” queries.
Fix: Add Service JSON-LD with name, description, provider, offers.price. ETA: 20 min for all three pages.
LOW LF-027 No canonical link on tool detail modals

Modals are client-rendered without dedicated URLs. Agents that snapshot the page see modal content out of context. Cosmetic for now — weighted 0.05 in rubric.
Fix: Either route modals (e.g. /tools/luxscope) or remove modal-only content from agent-visible HTML. ETA: dev-scoped.

Methodology deterministic · local · LLM-free

Crawl

BFS crawl up to depth 3 from root and sitemap entries. Honors robots.txt. Three parallel fetches per URL: Chromium (headless), LuxFaber UA, GPTBot UA.

Parse

Static HTML parser (no JS execution unless --render flag set). Extracts <head> meta, JSON-LD, OpenGraph, schema.org, microdata, semantic landmarks, alt coverage, heading tree.

Score

Five rules, weighted: Crawl 0.25, Structured 0.25, Semantic 0.15, Clarity 0.20, Determinism 0.15. Each rule is a deterministic checklist of sub-checks, no model calls. Same input → same score.

Privacy

No telemetry. No code or HTML leaves your machine unless you explicitly export the report. Open source: github.com/tinydarkforge/LuxFaber.
