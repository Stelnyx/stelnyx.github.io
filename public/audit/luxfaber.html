What Luxfaber actually checks

Deterministic static crawl. No JS rendering, no AI, no telemetry, no account. Open source under MIT.

  • Crawl Accessibility (weight 25): robots.txt, sitemap.xml, status codes, redirects, response time
  • Structured Data (weight 22): JSON-LD, Open Graph, Twitter Cards, schema.org coverage
  • Semantic HTML (weight 18): heading hierarchy, landmark roles, alt text, ARIA, link text quality
  • Content Clarity (weight 17): reading level, paragraph length, content-to-chrome ratio, ambiguous pronouns
  • Action Surface (weight 18): form labels, button affordances, navigable CTAs, agent-actionable signals

Common questions

Do you log into my site or scrape behind auth?
No. Public URLs only. Same access as Googlebot or any LLM crawler. If you want behind-auth coverage, we can quote that separately.
How is this different from a Lighthouse audit?
Lighthouse scores for human users on browsers. Luxfaber scores for LLM agents reading static HTML — different signal, different weights. JS-rendered SPAs that ace Lighthouse can score 20/100 here, because most agents do not run JS.
How many pages?
Up to 200 pages within the call. Larger crawls are fine but extend over a day or two — we'll deliver async if your site is bigger.
Is this just AI?
No. Luxfaber is 100% deterministic — same site always gives the same score. Findings are explainable rule-by-rule.
