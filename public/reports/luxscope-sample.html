Executive summary 3 paragraphs

stelnyx-web is a 19-file, 1,994-LOC Next.js 16 marketing site with one server-side surface (the contact API route) and a small set of client components. The architecture is shallow and well-bounded: components are organized by domain (hero, tools, contact, scores), there are no circular imports, and module fan-out is concentrated in two files (ToolsSection.tsx, ProductCard.tsx) which is appropriate for a content site. Dependency health is good — Next 16.2.4 and React 19.2.4 are both within 30 days of latest stable, no transitively vulnerable packages.

One HIGH-risk finding: app/api/contact/route.ts accepts unbounded JSON body and forwards selected fields to Resend without size or shape validation. A malicious caller can trigger large allocations or send crafted payloads. Two MED findings cover stale audit-page links pointing at buy.stripe.com/REPLACE_ME placeholders that would 404 in production, and a hardcoded support email in two places. Documentation is the lowest-scoring rule (70/100): of 19 files, only 2 have any JSDoc; public component props are mostly inferred.

Estimated time to address all HIGH + MED findings and lift overall score to 92+: ~3 hours, mostly in the contact route and link audit.

Findings 1 HIGH · 2 MED · 4 LOW

HIGH LS-101 Unbounded request body in contact API route
app/api/contact/route.ts:14 — await req.json()
The handler reads req.json() and destructures fields without size limit, type narrowing, or schema validation. A 50 MB JSON payload will allocate memory before any check runs; malformed input throws unhandled errors. Resend is then called with whatever string survives, so attacker-controlled content reaches the outbound mail body.
Fix: Add a Zod (or hand-rolled) validator: max 4 KB body, required fields with maxLength, email regex, optional captcha token. Reject early with 400. ETA: 30 min.
MED LS-204 Stripe placeholder URLs in shipped audit pages
public/audit/luxscope.html:78, public/audit/luxfaber.html:78, public/audit/secgate.html (2 occurrences)
Four occurrences of https://buy.stripe.com/REPLACE_ME in production-shipped HTML. Any user clicking the primary CTA hits a Stripe 404. Real impact: lost lead at the moment of purchase intent.
Fix: Either wire real Stripe payment links or replace with the existing ContactModal flow (already used elsewhere). ETA: 20 min.
MED LS-217 Hardcoded support email in two places
public/audit/luxscope.html:152, public/audit/luxfaber.html:152
String daniel.oceno@gmail.com appears in audit pages while daniel@hellocirrus.com is canonical elsewhere. Two sources of truth for the same contact channel; rebrand or redirect requires editing multiple files.
Fix: Centralize in a single config (e.g. lib/contact.ts exporting SUPPORT_EMAIL) and import where templated. ETA: 15 min.
LOW LS-301 Two unused exports in components/ui
components/ui/Modal.tsx (export ModalDivider), components/ui/Modal.tsx (export ModalSection)
Exported but no inbound references in the workspace. Likely scaffolded ahead of need.
Fix: Delete or annotate @internal. ETA: 5 min.
LOW LS-318 Implicit any on event handlers
components/contact/ContactModal.tsx (3 handlers), components/tools/ToolsSection.tsx (2 handlers)
Five inline handlers use untyped event parameters where TypeScript's inferred type is acceptable but explicit React event types would catch a future breaking change.
Fix: Add React.FormEvent<HTMLFormElement> / React.ChangeEvent annotations. ETA: 10 min.
LOW LS-322 Public component props lack JSDoc
components/products/ProductCard.tsx (Product type), components/contact/ContactModal.tsx (ContactContext type)
Two exported types are used across multiple components with non-trivial fields (audiences, tier, free, source). Inferring intent requires reading callers.
Fix: One-line JSDoc per field. ETA: 15 min.
LOW LS-340 No README onboarding section
README.md
Current README is 1.4 KB, mostly Next.js boilerplate. New engineer needs to grep for env vars (RESEND_API_KEY) and dev commands.
Fix: Add a 10-line “getting started” with required env, dev/build commands, and where the contact route logs go. ETA: 15 min.
